## 1. 데이터베이스 개요

### 시스템 구성
- **DBMS**: SQLite 3.x
- **인코딩**: UTF-8
- **총 데이터베이스**: 5개

## 5. SQL 쿼리 가이드

### 5.1 한글 컬럼명 처리

```sql
-- 한글 컬럼명은 큰따옴표로 감싸기
SELECT "담당자", "품목", "202410"
FROM sales_performance
WHERE "팀명" = '영업1팀'
```

### 5.2 월별 데이터 집계

```sql
-- 특정 기간의 총 실적
SELECT
    "담당자",
    "202401" + "202402" + "202403" as Q1_실적,
    "202404" + "202405" + "202406" as Q2_실적
FROM sales_performance
```

### 5.3 테이블 조인

```sql
-- 거래처 정보와 실적 조인
SELECT
    sp."담당자",
    sp."거래처ID",
    ci."병원명",
    sp."202410" as "10월실적"
FROM sales_performance sp
LEFT JOIN "거래처정보" ci ON sp."거래처ID" = ci.ID
```

### 5.4 목표 달성률 계산

```sql
-- 실적 대비 목표 달성률
WITH monthly_sales AS (
    SELECT
        "담당자",
        SUM("202410") as actual_sales
    FROM sales_performance
    GROUP BY "담당자"
)
SELECT
    ms."담당자",
    ms.actual_sales as 실적,
    st."202410" as 목표,
    ROUND(100.0 * ms.actual_sales / st."202410", 2) as 달성률
FROM monthly_sales ms
JOIN "영업실적목표" st ON ms."담당자" = st."담당자"
```

### 5.5 시계열 분석 (UNPIVOT)

```sql
-- 월별 데이터를 행으로 변환 (SQLite는 UNPIVOT 미지원, UNION 사용)
SELECT "담당자", '202401' as 월, "202401" as 판매액
FROM sales_performance
UNION ALL
SELECT "담당자", '202402' as 월, "202402" as 판매액
FROM sales_performance
-- ... 반복
```

### 5.6 NULL 처리

```sql
-- NULL 값을 0으로 처리
SELECT
    "담당자",
    COALESCE("202410", 0) as "10월실적"
FROM sales_performance
```

## 6. 성능 최적화 팁

1. **인덱스 생성 권장**
   ```sql
   CREATE INDEX idx_client_id ON sales_performance("거래처ID");
   CREATE INDEX idx_sales_person ON sales_performance("담당자");
   ```

2. **집계 쿼리 최적화**
   - WHERE 절을 먼저 적용하여 데이터 필터링
   - 불필요한 컬럼 제외
   - 적절한 GROUP BY 사용

3. **조인 최적화**
   - 작은 테이블을 먼저 조인
   - 조인 키에 인덱스 생성
   - LEFT JOIN보다 INNER JOIN 선호 (가능한 경우)

## 7. 제약사항 및 주의점

1. **Primary Key 부재**
   - 모든 테이블에 명시적 Primary Key 없음
   - 데이터 중복 가능성 있음

2. **한글 컬럼명**
   - 쿼리 작성 시 큰따옴표 필수
   - 일부 도구에서 호환성 문제 가능

3. **월별 컬럼 구조**
   - 동적 쿼리 생성 어려움
   - 새로운 월 추가 시 스키마 변경 필요

4. **데이터 타입 불일치**
   - 날짜가 TEXT로 저장됨
   - 계산 시 타입 변환 필요할 수 있음
