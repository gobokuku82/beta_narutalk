**2. 성과분석 데이터**

매체별로 분산된 광고 데이터를 통합·자동화하고, 성과 변화
원인(계절성·프로모션·소재 등)을 분석하기 위해 필요

  -----------------------------------------------------------------------
  **항목**         **내용**
  ---------------- ------------------------------------------------------
  왜 만들었나      매체별·캠페인별 일 단위 광고 성과를 기록하는 가장 핵심
                   데이터. 2024년 10월\~2025년 3월 6개월치. Prophet
                   계절성 학습 및 XGBoost 요인 분석을 위해 6개월치가
                   필요함

  어디에 쓰이나    성과분석 탭 KPI 카드(ROAS·광고비·전환수), 트렌드 차트,
                   30일 예측(Prophet), 요인 분석(XGBoost+SHAP)

  전처리 주의      날짜 str→datetime / CTR·CVR·ROAS % → 소수 변환 /
                   XGBoost 계절성 피처용 월·요일 파생 컬럼 생성 필요

  -------------------------------------------------------------------------
  **컬럼명**     **타입**   **설명**
  -------------- ---------- -----------------------------------------------
  날짜           문자열     광고가 집행된 날짜 (예: 2025-03-01)

  매체           문자열     광고가 집행된 플랫폼 (naver·kakao·meta·google)

  캠페인ID       문자열     캠페인 구분자. 캠페인목록 시트와 연결되는 키

  노출수         정수       해당 날짜에 광고가 몇 번 화면에 표시됐는지

  클릭수         정수       소비자가 광고를 몇 번 클릭했는지

  CTR(%)         소수       클릭률 = 클릭수 / 노출수. 광고 관심도 지표

  전환수         정수       광고를 보고 실제 구매까지 이어진 횟수

  CVR(%)         소수       전환율 = 전환수 / 클릭수

  CPC(원)        정수       클릭 1회당 광고비 (Cost Per Click)

  ROAS(%)        정수       광고 수익률 = 전환매출 / 광고비. 투자 대비 수익
                            지표

  CPA(원)        정수       전환 1건당 광고비 (Cost Per Action)

  광고비(원)     정수       해당 날짜에 실제로 지출된 광고비

  전환매출(원)   정수       광고를 통해 발생한 매출액

  CPM(원)        정수       1,000회 노출당 광고비

  소재ID         문자열     집행된 광고 소재 구분자. 광고소재 시트와 연결

**3. 소재분석 데이터**

광고 소재 피로도(CTR 감소)를 감지하고, 성과 기반으로 개선 방향을
도출하기 위해 필요

**① 광고소재 (46행 --- LLM 확장 전 원본)**

  -----------------------------------------------------------------------
  **항목**         **내용**
  ---------------- ------------------------------------------------------
  왜 만들었나      소재별 성과 지표(CTR·ROAS 등)와 피로도 정보. AI 모델이
                   \"이 소재가 피로한가?\"를 학습하는 데이터. LLM 확장을
                   통해 46행→200행 이상으로 늘린 후 학습

  어디에 쓰이나    소재 분석 탭 피로도 배지(정상·주의·위험), 교체 추천
                   목록, AI 어시스턴트 소재 개선 제안

  전처리 주의      CTR·CVR·ROAS % → 소수 변환 / 피로도
                   텍스트→fatigue_score·is_fatigue는 수정본에 이미 추가됨
                   / 시작일 str→datetime
  -----------------------------------------------------------------------

  ------------------------------------------------------------------------------------
  **컬럼명**                **타입**   **설명**
  ------------------------- ---------- -----------------------------------------------
  소재ID                    문자열     소재 구분자. 일별성과와 연결되는 키

  캠페인ID                  문자열     이 소재가 속한 캠페인

  소재명                    문자열     소재 이름

  매체                      문자열     이 소재가 집행되는 플랫폼

  규격                      문자열     소재 크기 (예: 1080×1080)

  CTR(%)·CVR(%)             소수       클릭률·전환율. AI 모델의 핵심 입력값

  ROAS(%)                   정수       광고 수익률. AI 모델의 입력값

  CPC(원)·CPA(원)           정수       클릭당·전환당 비용

  Frequency                 소수       소비자가 이 광고를 평균 몇 번 봤는지. 높을수록
                                       피로도 가능성 높음. AI 모델 핵심 입력값

  집행일수                  정수       이 소재를 얼마나 오래 집행했는지. AI 모델
                                       입력값
