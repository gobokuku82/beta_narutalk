## §0 어디서 일어났나 — 4원인 전수 추적 (코드 실측)

표시 텍스트의 조립 경로: tool들이 `data` dict 반환 → executor가 todo 별 보관 → **responder 가 텍스트 합성**
(M1-S1 신설: `_render_metrics` 스칼라 / `_render_breakdowns` dict·rows / 서술 합성). 오염은 이 합성 단계 3곳 + 상류 LLM 1곳.

| # | 증상 (오너 캡처) | 발생 위치 | 기전 |
|---|---|---|---|
| ① 배관 누출 | `meta_ads_raw — _dataref: True · where: self.ds.get…`, `orders_active — _state_guard: slimmed`, `mapping — unknown: Unknown…` | `responder.py` `_render_breakdowns` dict 분기 | 거름망이 "dict 이고 스칼라 값이면 분해 결과"라고 판단 — **G17 참조 스텁(_dataref)·G16 슬리밍 스텁(_state_guard)·normalizer 내부 매핑표도 dict 라서 통과**. 스텁은 게이트 장치인데 표시가 그걸 데이터인 줄 앎 |
| ② 지표 모순 | 본문 ROAS **6.53** vs `평균 ROAS: 395.01%` vs `avg_roas: 392.64` + 광고비 1,831만/2,657만 두 개 | tool 정의 분기 (표시는 노출만) | (a) **분모 2종**: `roas_overall` = orders 매출 ÷ `aggregate_ad_cost`(1,831만) / `daily_performance_totals` = ad_cost 2,657만 — 비용 우주가 둘. (b) **단위 혼재**: 배(6.53) vs %(395). (c) **라벨 무맥락**: `creative_roas_avg` 기본 label="평균 ROAS"(실은 *소재* 평균), `keyword_metrics_avg.avg_roas`(실은 *키워드* 평균) — 셋 다 "ROAS"로 보임. 기존 백로그 "혼합 집계(3월 ROAS 1111%)" 가족 |
| ③ rows 소음 | creative 행에 `image_url · landing_url · start_date · frequency…` 벽 | `responder.py` `_render_breakdowns` rows 분기 | 행 수만 cap(10) 하고 **컬럼 폭은 무제한** — URL·ID·날짜류까지 전부 |
| ④ **LLM 거짓 주장** | 인사이트 "신규 회원 600명 중 **81명 이탈**" — 사실 아님 | `insight_extractor` (LLM 입력 단계) | `active_orders_filter` 의 `dropped: 81` = **비활성 주문 81건 제거**(정제 부산물)인데, LLM 이 previous_results 에서 이 키를 보고 "회원 이탈 81명"으로 **오해석 → 존재하지 않는 비즈니스 사실 생성**. G12 는 SKIP/FAILED dict 만 거름 — 완료 todo 의 내부 보조 수치는 통과 |

부수: `pdf_file_path` 가 attachment 와 텍스트에 중복 (`_render_metrics` 스칼라 루프 — `_FILE_ARTIFACTS` 키 미제외).

**구조 해석**: ①③은 M1-S1 의 신규 버그(거름망 부족 — 반나절감). ②는 기존 지표 정의 문제의 *노출*(수술이 아니라 폭로 —
계산 기준은 오너 영역). ④는 표시가 아니라 **분석 신뢰성** 문제 — H4(거짓말 금지) 위반 류로 4원인 중 가장 심각.

## §2 수술안

- **R1** `_render_breakdowns`: dict 값에 `_dataref`/`_state_guard` 키가 있으면 skip (스텁 = 게이트 장치, 표시 대상 아님).
  내부 산출 키 deny 추가: `mapping` 등 — 단 deny 목록 비대화 방지 위해 "스텁 마커 우선, 이름 deny 는 최소" 원칙.
- **R2** rows 렌더: 컬럼 수 cap(6) + 패턴 제외(`*_url`, `*_id`, `image*`, `landing*`, 날짜류 `*_date`/`start_*`/`end_*`) — 규칙 기반.
- **R3** `_render_metrics`: `_FILE_ARTIFACTS` 키 제외 (attachment 단일 통로).
- **R4** (오너 결정 §5-1 후): ROAS 분모 단일화 또는 라벨 강제("미디어 ROAS"/"전체 ROAS") + 단위 통일(배 또는 %).
  코드 후보: `aggregate_ad_cost` ↔ `daily_performance` 비용 정의 정합 + label 기본값 맥락화("소재 평균 ROAS" 등).
- **R5** (오너 결정 §5-2 후): LLMTool 입력 조립에서 **정제 부산물 키 제외 목록**(dropped/before_count/after_count 류)
  또는 키 의미 주석 전달(provenance) — ⓐ가 작고 안전, ⓑ가 근본적. 권장 = ⓐ 즉시 + ⓑ는 H2 와 통합 백로그.

## §3 테스트 계획

1. 단위 (test_m1_display_merge.py 증설): 스텁 dict 미렌더 / mapping 미렌더 / rows 컬럼 cap·URL 제외 / 파일경로 텍스트 미중복 / R5 — dropped 가 LLM 입력 payload 에 안 들어감 (LLMTool 입력 조립 단위).
2. 회귀: 전체 suite + T3 표출률 비역행 (66.7% 기준 — 거름망 강화가 정당 표출을 깎지 않는지 검증, ±변동폭 9.7%p 감안).
