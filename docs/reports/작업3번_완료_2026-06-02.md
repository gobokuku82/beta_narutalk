## §2 2026 표준 (WebSearch 종합)

### 2.1 핵심 권장 패턴

| 영역 | 표준 권장 | 출처 |
|---|---|---|
| **feature-based 구조** | `src/features/{domain}/` | Robin Wieruch / DEV 2025 / Medium |
| **도메인 colocation** | `{domain}/{components, hooks, utils, types}/` 서브 (大 도메인) 또는 flat (小 도메인) | Robin Wieruch |
| **공용** | `src/components/`, `src/lib/`, `src/api/` | DEV / Medium |
| **상태 관리 분담** | Zustand = UI/client state / TanStack Query = server state | Robin Wieruch |
| **빌드** | Vite (기본 선택) | patterns.dev React 2026 |
| **라우팅** | TanStack Router (file-based or code-based) | TanStack docs |

### 2.2 stack 추천

- React 19 + Vite + TypeScript + TanStack Router + TanStack Query + Zustand + Tailwind + shadcn = 2026 표준 stack

## §3 대조 결과

### 3.1 정합 항목 (★★★★★)

| 표준 항목 | 현 구조 | 정합 |
|---|---|---|
| feature-based | `src/features/{21}` | ✓ |
| 도메인 colocation | `features/{name}/{store.ts, XPage.tsx, hooks 등}` | ✓ |
| 공용 components | `src/components/{ui, layout, charts}` | ✓ |
| 공용 lib | `src/lib/` | ✓ |
| API layer | `src/api/{rest, schemas, hooks/}` | ✓ |
| 라우팅 | code-based router.tsx (의도 선택, file-based 대안 폐기 자취) | ✓ |
| 상태 분담 | Zustand store + useCategoryResults (TanStack Query) | ✓ |
| 테스트 colocation | `*.test.ts` same folder | ✓ |
| 빌드 | Vite 5 | ✓ |
| 기술 stack | React 19 + Vite + TS + TanStack Router/Query + Zustand + Tailwind + Radix/shadcn | ✓ 2026 표준 stack |

### 3.2 현 구조 특이점 (모두 정상)

1. **`_pipeline/` underscore prefix** = 공용 utilities 마킹 (`periods`, `viz`, `RefreshButton`)
   - 비표준 컨벤션이지만 명확 (일부 프로젝트 패턴)
2. **features 내부 flat** (workflow 외) = 도메인 작아서 서브폴더 불요
   - Robin Wieruch 권장 = "도메인 크기에 따라 flat or nested 선택"
3. **`features/workflow/` 서브폴더 5개** = 복잡 도메인 표준 정합
4. **code-based router** = file-based 대안 (사용자 의도, routes/README.md 박제)

### 3.3 잠재 개선 (POC = 시기상조, 변경 X 권장)

| 후보 | 표준 권장 | 현 상태 | 판단 |
|---|---|---|---|
| features 내부 components/hooks 서브폴더 분리 | 大 도메인 시 권장 | flat (small 도메인 = 정합) | 변경 X |
| types/ 도메인별 분리 | feature 내 `types.ts` | `api/schemas.ts` 단일 진실 | 변경 X (단일 진실도 valid) |
| `e2e/` 폴더 | playwright 표준 | 부재 + `playwright.config.ts` testDir 박제 | 별개 작업 (작업 1 §5 자취) |
