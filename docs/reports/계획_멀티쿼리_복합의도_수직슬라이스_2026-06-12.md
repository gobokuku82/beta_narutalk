## 2. M0 — e2e 측정 설계 (제품 코드 무수정, 측정기 소수정 4건 — 전부 File 백엔드로 실행, 스크립트 기본)

기존 자산 재사용이 원칙 — corpus 14쿼리(lv1~lv5)·judge 교정·multi-run 분류(stable/systematic/flaky) 전부 있음. 비는 곳만 채운다:

| # | 정비 | 사유 |
|---|---|---|
| T1 | `baseline_compound.py` 출력 파일명 = corpus stem + **run-id(실행일)** — 같은 corpus 재실행도 기존 파일 비파괴 | 신규 corpus·재실행 모두 기존 회귀 기준선(98.5%) clobber 방지 (실측 L183·L236 고정명) |
| T2 | `measure_stage1_coverage.py` --corpus 인자화 + multi-run + 출력 stem 분리(T1 동일) + **corpus 키 호환(`type`/`kind` fallback)** + **레코드에 sub_intents 추출(n_sub·sub_ops — ①단 지표 수집)** | 유일한 full-graph 측정기인데 corpus 하드코딩(:82)·1회 스냅샷 구조 + corpus 파일 간 키 불일치 실측. (동종 단발 측정의 변동은 cog+planning 계보에서 실증: 96%[06-09]→89%[06-10] 스냅샷, multi-run 진값 93.5%) |
| T3 | **다중 산출 표시 판정기 신설** — 응답 text/summary/attachments에 의도별 산출이 포함됐는지 판정 (expect_display 필드를 corpus에 추가) | ④단(의도별 표출)을 정량화하는 측정기 부재 (REAL/DEGRADE/EMPTY 거친 판정만 존재) |
| T4 | **의도→todo 귀속 판정기 (측정 전용)** — 기존 judge의 의도별 evidence_tool(score_coverage)과 plan/실행 tools의 결정론 join(_reconcile_judge 패턴 + TodoResult.tool) 재사용 | ③단 지표 "의도별 완주율"의 산출 수단 — 제품 코드 무수정 유지. 없으면 ③단은 halt 전파율(귀속 불요)로 격하 |

**실행**: corpus_compound 14쿼리 × **3런 경향** full-graph (런당 LLM = 전 레이어 — 비용은 [[project_llm_heavy_initial]] 허용 범위) + **수술표에서 '채택' 근거가 되는 쿼리만 5런 추가** (systematic 판정을 기존 기준선과 동급으로). 계획층 **fresh 재기준선은 별도 1회** — `baseline_compound --runs 5` (06-11과 동일 headless 하네스·런수 — 동급 대조 성립 조건). 측정 4단 통과율: 인식(n_sub) / 계획(coverage — fresh 재기준선 박제 후 신구 대조) / 실행(의도별 완주율[T4]·halt 전파·**FAILED 시 타 의도 todo의 phase 위상 분기율**) / **표시(의도별 산출 표출률 — 메트릭-메트릭/이질-이질 조합 분리 태깅)**.

**산출(DoD)**: 측정 보고서 + **수술표** (§3 후보의 채택/기각/서열 — 헌법 §7-1 측정 근거 충족) + **G8 원문 확정**(실측에서 실제 FAILED를 낸 쿼리 기반) + **[3] 판정 임계의 재료**(표출률의 런간 변동폭 실측 — v2에서 수치 확정) → 본 계획 v2로 승격 → 오너 승인 → M1.
