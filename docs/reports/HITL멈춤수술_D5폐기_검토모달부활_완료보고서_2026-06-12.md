# 완료보고서 — HITL 간헐 멈춤(~1/20) 수술: D5 자동승인 폐기 + 검토 모달 부활

> 일자: 2026-06-12 · 오너 결정: 방향 1("검토 ON = 사람이 확인 후 실행" 복원) + timeout 30분 동결(ON/OFF 선택권 존재)
> 특기: **서버 코드 무수정 수술** — 서버는 방향 1에 맞게 이미 지어져 있었음

## 1. 무엇이 멈추게 했나 (확정 진단)

```
검토 ON(기본값) → 서버: 계획 완성 후 일시정지, "승인?" 송신 [agent 소켓]
  → frontend: 사람에게 보여주기 전에 코드가 즉시 자동 approve 송신 [hitl 소켓]  ← D5 자동승인
    → 서버: 재개
```

- **D5 자동승인**이 검토 모달(PlanReviewModal — 이미 구현돼 있었음)을 dormant로 만들었고, 토글 라벨("ON=사용자가 확인 후 실행")과 실동작이 어긋남. 오너 증언: 방향 1로 잘 되고 있었는데 어느 시점 의도 전달 오류로 D5 도입.
- 판단 없는 자동 왕복이 **WS 순단(1초 자동 재연결 창)과 겹치면** 신호가 유실되고, 유실 복구 수단이 없어 서버가 `HITL_RESUME_TIMEOUT_SEC`(30분)을 침묵 대기 → 사용자 체감 "멈춤". 발생률 ~1/20 = 왕복 체공 시간 × 순단 빈도.
- 구멍 3종 전부 코드 확정: ① hitl_request 유실 시 재요청 부재(서버 resume_query 경로는 있었고 **호출자 0**) ② 자동 approve 전송 실패가 콘솔만(재시도 0) ③ ack accepted:false 무반응.
- 보조 발견: 이 영역 회귀 테스트 11건이 **하네스 부패**(sprint14 픽스처 2곳만 구 평면 연결구조 — sprint13은 갱신됨)로 헛붉어 고장 감시가 꺼져 있었음. timeout 장치 자체는 멀쩡.

## 4. 오너 확인 1분 (실클릭)

검토 토글 **ON** 상태로 질문 1개 → **계획 검토 모달이 떠야 정상** → 승인 클릭 → 실행 진행. (OFF면 이전처럼 모달 없이 바로 실행.) 모달이 안 뜨거나 어색하면 말씀 — 잠들어 있던 UI라 미세 빛부식 가능성은 남아 있습니다.
