## 2. 계획서에 주는 의미 (반영 내역)

1. **P가 더 쉬워졌다**: 시범 경로의 행-데이터는 살아 있고(E2), SQL은 스케치보다 단순하며(E3), 효과는 이미 수치로 실증(E4 — §6의 before/after 박제 절반이 선납됨). V1 처방에 경량 옵션(마커 복원) 추가. 단 V2(마커 생존 가드)의 필요성은 그대로 — 마커가 실제로 한 번 죽었음이 라이브 증거.
2. **Q의 M0 필요성이 측정으로 지지**: E10이 보여준 "계획 단계 의도 탈락"은 1런짜리 데이터점이지만, fresh 재기준선(regime 단서)이 형식적 보완이 아니라 실질임을 보여줌. G7 빨간불의 원인 축이 2개(계획 탈락 / 표시 탈락 — E8)임을 §4에 명시.
3. **M 순서는 유지** — 테스트 기반 검증에서 순서를 흔드는 발견 없음.

## 3. 방법 한계 (정직)

- e2e 파일럿은 **1런** — LLM 비결정 위에서 단정 불가, M0(3런+선별 5런)가 본 측정.
- V2 메커니즘(수집기가 마커를 덮는 과정)은 라이브 결과로 간접 확증 — 재현 실험(throwaway 스키마)은 M0/[2]에서.
- LLM 비용: 파일럿 1쿼리 ≈ LLM 5회 (cognitive 1·planning 3·summary 1) — [[project_llm_heavy_initial]] 허용 범위.
