# 완료보고서 — 게이트 대장(spec 43) 신설: "표가 진실, 그림은 생성물" 구조도 전략

> 일자: 2026-06-12 · 오너 지시: "8gate 외 검증 게이트가 많아져 시각화가 복잡 — 어떻게?" → 구조도(게이트 대장)만 먼저

## 1. 무엇을

- **[43 Gate Ledger](../agent_specs/43_gate_ledger_v1.0.md) 신설** — 런타임 검증·수선 게이트 **27개 전수 등기** (G01~G27, 전 행 코드 위치 실측 + 박제 테스트 명기). 분류: cognitive 신호 1 · planning plan-repair 7 · execution 입구 6 / 출구 3 · response 정직 표면 4 · 시스템·관측 3 · frontend 3. + 데이터 평면 관절(pushdown 예정 포함) + 오프라인 하네스 요약.
- **그림은 파생물**: `scripts/generate_gate_map.py`가 표에서 Mermaid 구조도를 재생성하고, `test_gate_ledger_sync.py`가 표↔그림 불일치를 RED로 강제 — 손그림 세부도가 썩는 문제를 기계로 차단.
- **헌법 19 → v1.0.1 동기**: §5 라우팅 표에 신호 6행 등재(슬라이스 1 배선분 ✅ 3 + 미등재였던 `_state_guard`·`_dataref` 스텁·`hitl_request` 사람승인) + D5 제거 박제 + §8 슬라이스 상태 ✅ + 43 링크. (근본원인 보고서 §9.3-4 처방 이행)

## 2. 사용법 (오너)

- "지금 검증 장치가 뭐가 있지?" → **43 한 장**. 게이트 추가/폐기 = 표 한 줄 수정 → `python -m scripts.generate_gate_map` → 그림 자동 갱신.
- 새 게이트 채용 조건은 변함없음: 헌법 §7 3문항(측정 근거/소속 층/신호 소비자) + §5 신호 등록.
- 큰 그림(4-Layer 한 장)은 포트폴리오 AgentLayerDiagram이 담당 — 43은 세부(게이트) 층.
